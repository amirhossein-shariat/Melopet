# ملوپت — اپلیکیشن آزمایشگاه دامپزشکی 🐾

اپ اندروید ملوپت برای کلینیک‌ها و بیمارستان‌های دامپزشکی همکار، به همراه پنل ادمین آزمایشگاه.

```
Melopet/
├── app/       ← اپ Flutter (اندروید؛ نسخه وب فقط برای پیش‌نمایش)
├── backend/   ← سرور (PocketBase + Go): دیتابیس، احراز هویت، فایل‌ها، چت لحظه‌ای، اعلان‌ها
└── .github/workflows/build.yml  ← ساخت خودکار APK و فایل اجرایی سرور
```

## امکانات

| بخش | توضیح |
|---|---|
| ورود یکسان | یک صفحه ورود برای همه؛ همکار با شماره موبایل، ادمین با **شناسه مخصوص ادمین** (نقش را سرور تعیین می‌کند) |
| ثبت‌نام یک‌باره | ۴ مرحله: حساب (موبایل + رمز)، مشخصات مرکز، آدرس + **انتخاب لوکیشن روی نقشه** (با دکمه موقعیت فعلی)، لوگو و سربرگ |
| درخواست پیک — مرحله ۱ | اطلاعات کیس: نام صاحب، نام حیوان، نوع حیوان (الزامی)، نژاد، سن، جنس، وزن، شماره پرونده + **تاریخچه کیس (History)** به صورت متن و/یا **ویس** (ضبط داخل اپ یا آپلود فایل صوتی). بدون History به مرحله بعد نمی‌رود (سرور هم بررسی می‌کند) |
| درخواست پیک — مرحله ۲ | انتخاب فاکتورهای آزمایشگاهی از لیست + **جستجو** (نام/کد) + فیلتر بخش، نمایش جمع مبلغ. بعد از ارسال، **نوتیفیکیشن برای آزمایشگاه** (نام مرکز، حیوان، تعداد آزمایش) |
| پیگیری سفارش | تایم‌لاین وضعیت: ثبت ← پیک در راه ← نمونه دریافت شد ← در آزمایشگاه ← در حال انجام ← جواب آماده |
| جواب آزمایش | جدول نتایج با محدوده مرجع مخصوص هر گونه (سگ/گربه) و علامت H/L |
| خروجی | PDF روی **سربرگ خود کلینیک** (با تنظیم فاصله بالا/پایین)، PDF با سربرگ ملوپت، Excel، چاپ، اشتراک‌گذاری |
| چت | شبیه تلگرام: متن، عکس، فایل، **پیام صوتی**، پاسخ (کشیدن پیام)، تیک خوانده‌شدن، جداکننده تاریخ. **پیام‌ها قابل حذف یا ویرایش نیستند** (حتی برای ادمین؛ در سطح سرور بسته شده) |
| پیشنهادها | تخفیف‌ها با بنر، درصد، کد تخفیف و تاریخ انقضا + ارسال نوتیفیکیشن برای همه |
| اعلان‌ها | جواب آماده، تغییر وضعیت پیک، پیام جدید، تخفیف جدید، تایید حساب |
| تماس با ما | نقشه با پین آزمایشگاه + دکمه **مسیریابی با نشان**، تلفن، موبایل، واتساپ، تلگرام، اینستاگرام، ساعات کاری |
| ظاهر | صورتی پاستلی + مکمل‌های نعنایی و یاسی، شیشه‌ای (blur)، حالت روشن/تیره/خودکار، فونت وزیرمتن، تاریخ شمسی |

### پنل ادمین (با همان اپ، با حساب ادمین وارد شوید)
- داشبورد: درخواست‌های جدید، سفارش‌های در جریان، پیام‌های خوانده‌نشده، همکاران در انتظار تایید، جمع مبالغ
- مدیریت سفارش: شنیدن ویس History، لوکیشن محل نمونه با مسیریابی نشان برای پیک، مرحله بعد با یک دکمه، ثبت نام/شماره پیک، **ورود جواب** (با هشدار رنگی بالا/پایین بودن)، پیوست فایل جواب، انتشار جواب ← نوتیفیکیشن به همکار
- همکاران: تایید حساب، **سطح طلایی/نقره‌ای/برنزی** (فقط ادمین می‌بیند)، ریست رمز، ثبت سفارش از طرف همکار
- آزمایش‌ها: سه قیمت جدا برای هر آزمایش + انتخاب اینکه آزمایش در لیست کدام سطح دیده شود + پارامترها و محدوده مرجع
- تخفیف‌ها، اعلان همگانی، اطلاعات تماس آزمایشگاه، خروجی Excel سفارش‌ها

### حریم قیمت‌ها
همکار هیچ‌وقت سطح خودش یا قیمت سطوح دیگر را نمی‌بیند: جدول آزمایش‌ها فقط برای ادمین خواناست و همکار
از مسیر `/api/melopet/catalog` فقط **قیمت خودش** را می‌گیرد. مبلغ سفارش هم روی سرور حساب می‌شود (قابل دستکاری از سمت گوشی نیست).

## دریافت APK

هر push به گیت‌هاب، APK را در GitHub Actions می‌سازد:
**Actions ← Build Melopet ← آخرین اجرا ← Artifacts ← `melopet-apk`**

آدرس سرور داخل APK قرار می‌گیرد. دو راه:
1. **Settings ← Secrets and variables ← Actions ← Variables** یک متغیر `API_URL` (مثلا `https://api.melopet.ir`) بسازید، یا
2. **Actions ← Build Melopet ← Run workflow** و آدرس را در فیلد `api_url` وارد کنید.

برای تست هم می‌توانید در صفحه ورود **روی لوگو انگشت را نگه دارید** و آدرس سرور را عوض کنید.

برای انتشار نسخه دانلودی: یک تگ مثل `v1.0.0` بزنید تا Release با APK و فایل سرور ساخته شود.

> امضای نسخه نهایی: یک keystore بسازید و در Secrets مقادیر `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD` را بگذارید. بدون آن، APK با کلید debug امضا می‌شود (برای تست کافی است، برای کافه‌بازار/مایکت نه).

## راه‌اندازی سرور

سرور یک فایل اجرایی است (بدون نیاز به دیتابیس جدا). روی یک VPS ایرانی (مثلا ابرآروان، پارس‌پک) اجرا کنید تا برای کاربران داخل ایران سریع و بدون فیلتر باشد.

```bash
# فایل melopet-server-linux-amd64 را از Artifacts یا Release دانلود کنید
chmod +x melopet-server-linux-amd64

# رمز ادمین اولیه (فقط در اولین اجرا اعمال می‌شود)
export MELOPET_ADMIN_MOBILE=09xxxxxxxxx
export MELOPET_ADMIN_PASSWORD='یک-رمز-قوی'
export MELOPET_ADMIN_ID=melopet            # شناسه ورود ادمین

./melopet-server-linux-amd64 serve --http=0.0.0.0:8090
# یا با دامنه و HTTPS خودکار:
./melopet-server-linux-amd64 serve api.melopet.ir
```

- اگر متغیرها را تنظیم نکنید، ادمین پیش‌فرض: شناسه `melopet` (یا موبایل `09000000000`) و رمز `melopet-admin-1234` — **فورا رمز را عوض کنید** (پروفایل ← تغییر رمز).
- ادمین در همان صفحه ورود اپ، به جای شماره موبایل، شناسه ادمین را وارد می‌کند. همکاران نمی‌توانند برای خود شناسه ادمین بسازند.
- لوکیشن آزمایشگاه برای «تماس با ما»: پنل ادمین ← بیشتر ← اطلاعات تماس آزمایشگاه ← لوکیشن.
- داشبورد مدیریتی دیتابیس: `https://آدرس-سرور/_/` (اولین بار یک superuser بسازید: `./melopet-server superuser upsert EMAIL PASS`). از اینجا می‌توانید ادمین جدید بسازید (کاربری با `role = admin`)، بکاپ بگیرید و ...
- `MELOPET_AUTO_APPROVE=true` ← همکاران جدید بدون تایید ادمین بتوانند پیک درخواست کنند.
- همه داده‌ها در پوشه `pb_data` کنار فایل است؛ از آن بکاپ منظم بگیرید (داشبورد ← Settings ← Backups).

### اجرای محلی برای توسعه
```bash
cd backend && go run . serve                      # سرور روی 127.0.0.1:8090
cd app && flutter run --dart-define=API_URL=http://10.0.2.2:8090   # امولاتور اندروید
```

## داده‌های اولیه (از عکس‌های نرم‌افزار آزمایشگاه)

| آزمایش | قیمت همکار |
|---|---|
| CBC | ۴۰۰٬۰۰۰ |
| AST، ALT، ALP، Chol، TG، Glu، GGT | ۹۵٬۰۰۰ |

- هر سه سطح (طلایی/نقره‌ای/برنزی) فعلا با همین «قیمت همکار» پر شده‌اند؛ از **پنل ادمین ← آزمایش‌ها** برای هر سطح قیمت جدا بگذارید. همکار جدید به‌طور پیش‌فرض برنزی است.
- قیمت GGT همکار در عکس دیده نمی‌شد، ۹۵٬۰۰۰ فرض شد.
- واحد پول «تومان» فرض شده (در `app/lib/utils/format.dart` ← `kCurrency` قابل تغییر است).
- محدوده‌های مرجع سگ و گربه مقادیر رایج منابع هستند و **باید توسط مسئول فنی با دستگاه‌های خود آزمایشگاه بازبینی شوند** (از پنل ادمین قابل ویرایش‌اند).
- بقیه بخش‌ها (Urinalysis، Fluid، Culture، Hormone، Biopsy، PCR و ...) دسته‌بندی‌شان آماده است؛ با فرستادن لیست کامل اضافه می‌شوند. آزمایش‌های بدون پارامتر عددی (مثل کشت یا بیوپسی) یک کادر «گزارش متنی» دارند.

## لوگو
لوگوی فعلی موقت است (قطره خون + پنجه). برای جایگزینی:
1. فایل PNG مربع ۱۰۲۴×۱۰۲۴ را در `app/assets/images/logo.png` بگذارید و اجرا کنید: `python3 app/tool/make_icons.py --from app/assets/images/logo.png`
2. ویجت `MelopetLogo` در `app/lib/widgets/logo.dart` را با `Image.asset('assets/images/logo.png')` عوض کنید.

## نوتیفیکیشن
- وقتی اپ باز یا در پس‌زمینه است: لحظه‌ای (Realtime).
- وقتی اپ بسته است: هر ~۱۵ دقیقه یک بررسی پس‌زمینه (WorkManager) اعلان‌های جدید را نشان می‌دهد.
- این روش به سرویس‌های گوگل وابسته نیست و در ایران کار می‌کند. برای اعلان **کاملا آنی** با اپ بسته، می‌توان بعدا سرویس پوشه (Pushe) یا نجوا یا FCM را به تابع `notify()` در `backend/hooks.go` وصل کرد — ساختار داده تغییری نمی‌کند.
