# ملوپت — اپلیکیشن آزمایشگاه دامپزشکی 🐾

اپ اندروید ملوپت برای کلینیک‌ها و بیمارستان‌های دامپزشکی همکار، به همراه پنل ادمین آزمایشگاه.

```
Melopet/
├── app/       ← اپ Flutter (اندروید؛ نسخه وب فقط برای پیش‌نمایش)
├── backend/   ← سرور (PocketBase + Go): دیتابیس، احراز هویت، فایل‌ها، چت لحظه‌ای، اعلان‌ها
└── .github/workflows/build.yml  ← ساخت خودکار APK و فایل اجرایی سرور
```

## امکانات

| بخش | توضیح |
|---|---|
| ورود یکسان | یک صفحه ورود برای همه؛ همکار با **شماره موبایل + کد ۴ رقمی پیامکی**، ادمین با **شناسه مخصوص ادمین + رمز** (نقش را سرور تعیین می‌کند) |
| ثبت‌نام یک‌باره | بعد از تایید کد پیامکی، ۳ مرحله: مشخصات مرکز، آدرس + **انتخاب لوکیشن روی نقشه** (با دکمه موقعیت فعلی)، لوگو و سربرگ |
| درخواست پیک — مرحله ۱ | اطلاعات کیس: نام صاحب، نام حیوان، نوع حیوان (الزامی)، نژاد، سن، جنس، وزن، شماره پرونده + **تاریخچه کیس (History)** به صورت متن و/یا **ویس** (ضبط داخل اپ یا آپلود فایل صوتی). بدون History به مرحله بعد نمی‌رود (سرور هم بررسی می‌کند) |
| درخواست پیک — مرحله ۲ و ۳ | انتخاب فاکتورهای آزمایشگاهی از لیست + **جستجو** (نام/کد) + فیلتر بخش؛ سپس **نحوه ارسال**: عادی رایگان (حداکثر ۴ ساعت) یا فوری با هزینه‌ی اضافه. بعد از ارسال، **نوتیفیکیشن برای آزمایشگاه** (نام مرکز، حیوان، تعداد آزمایش) |
| پیگیری سفارش | تایم‌لاین وضعیت: ثبت ← پیک در راه ← نمونه دریافت شد ← در آزمایشگاه ← در حال انجام ← جواب آماده |
| جواب آزمایش | جدول نتایج با محدوده مرجع مخصوص هر گونه (سگ/گربه) و علامت H/L |
| خروجی | PDF روی **سربرگ خود کلینیک** (با تنظیم فاصله بالا/پایین)، PDF با سربرگ ملوپت، Excel، چاپ، اشتراک‌گذاری |
| چت | شبیه تلگرام: متن، عکس، فایل، **پیام صوتی**، پاسخ (کشیدن پیام)، تیک خوانده‌شدن، جداکننده تاریخ. **پیام‌ها قابل حذف یا ویرایش نیستند** (حتی برای ادمین؛ در سطح سرور بسته شده) |
| پیشنهادها | تخفیف‌ها با بنر، درصد، کد تخفیف و تاریخ انقضا + ارسال نوتیفیکیشن برای همه |
| اعلان‌ها | جواب آماده، تغییر وضعیت پیک، پیام جدید، تخفیف جدید، تایید حساب |
| تماس با ما | نقشه با پین آزمایشگاه + دکمه **مسیریابی با نشان**، تلفن، موبایل، واتساپ، تلگرام، اینستاگرام، ساعات کاری |
| ساعت و روز کاری | ساعت شروع/پایان با چرخ انتخاب (بدون تایپ)، روزهای کاری با لمس، و پاسخ اجباری «در تعطیلات رسمی تعطیل هستید؟» |
| دکمه برگشت | یک بار Back: برگشت به صفحه اصلی؛ در صفحه اصلی: پرسش «خروج از برنامه؟» با دو گزینه |
| ظاهر | صورتی پاستلی + مکمل‌های نعنایی و یاسی، شیشه‌ای (blur)، حالت روشن/تیره/خودکار، فونت وزیرمتن، تاریخ شمسی |

### پنل ادمین (با همان اپ، با حساب ادمین وارد شوید)
- داشبورد: درخواست‌های جدید، سفارش‌های در جریان، پیام‌های خوانده‌نشده، همکاران در انتظار تایید، جمع مبالغ
- مدیریت سفارش: شنیدن ویس History، لوکیشن محل نمونه با مسیریابی نشان برای پیک، مرحله بعد با یک دکمه، ثبت نام/شماره پیک، **ورود جواب** (با هشدار رنگی بالا/پایین بودن)، پیوست فایل جواب، انتشار جواب ← نوتیفیکیشن به همکار
- همکاران: تایید حساب، ریست رمز، ثبت سفارش از طرف همکار، حسابرسی
- آزمایش‌ها: یک قیمت برای هر آزمایش (خالی = توافقی) + پارامترها و محدوده مرجع
- تخفیف‌ها، اعلان همگانی، اطلاعات تماس آزمایشگاه
- **حسابداری همکاران**: مانده بدهی هر مرکز، گزارش مطالبات (PDF)، تایید یا رد پرداخت‌های ثبت‌شده، ثبت پرداخت دریافتی

### لیست آزمایش‌ها و قیمت‌ها
لیست قیمت همکار آزمایشگاه (۴۸ آزمایش از فایل `k1.xlsx`) در پایگاه داده و نسخه نمایشی هست؛ قیمت‌ها به تومان است
(مثلا `CBC = ۴۰۰` یعنی ۴۰۰٬۰۰۰ تومان) و موارد «*» با قیمت **توافقی** ثبت شده‌اند.
ادمین از «بیشتر ← آزمایش‌ها و تعرفه‌ها» می‌تواند آزمایش اضافه، ویرایش، غیرفعال یا حذف کند، قیمت را تغییر دهد
و بر اساس بخش فیلتر و جستجو کند. سطح‌بندی طلایی/نقره‌ای/برنزی حذف شده و همه‌ی همکاران یک قیمت می‌بینند.
محدوده مرجع (H/L) برای آزمایش‌های تازه‌اضافه‌شده خالی است تا مسئول فنی مقادیر معتبر دستگاه‌های آزمایشگاه را وارد کند.

### حسابرسی و پرداخت
همکار از «سفارش‌ها ← حسابرسی و پرداخت» بدهی خود را برای «این ماه»، «ماه قبل»، «۳۰ روز اخیر» یا «همه» می‌بیند،
صورت‌حساب **PDF** (سفارش‌ها، پرداخت‌ها، مانده و شماره کارت) می‌گیرد، شماره کارت آزمایشگاه را کپی می‌کند و پس از
کارت‌به‌کارت، مبلغ و شماره پیگیری را در برنامه ثبت می‌کند. پرداخت «در انتظار تایید» می‌ماند و تا تایید آزمایشگاه از بدهی
کسر نمی‌شود؛ تایید یا رد آن اعلان می‌گیرد. مانده = مجموع سفارش‌های غیرلغوشده − پرداخت‌های تاییدشده.
شماره کارت، نام صاحب کارت و بانک از «بیشتر ← اطلاعات تماس آزمایشگاه» تنظیم می‌شود.

### نحوه ارسال (مرحله ۳ درخواست پیک)
مثل فروشگاه‌های اینترنتی، در آخر نحوه‌ی ارسال انتخاب می‌شود:
- **ارسال عادی — رایگان:** آزمایشگاه هر ۴ ساعت یک دور پیک می‌فرستد، پس نمونه حداکثر تا ۴ ساعت دیگر برداشته می‌شود.
  (فاصله‌ی دورها از «اطلاعات آزمایشگاه ← پیک و ارسال» قابل تغییر است.)
- **ارسال فوری (پیک اختصاصی):** هزینه برای مسیر «محل دریافت نمونه ← آزمایشگاه» همان لحظه قیمت‌گذاری می‌شود و **به مبلغ کل سفارش اضافه**
  می‌شود (در فاکتور، صورت‌حساب و بدهی همکار هم می‌آید).

مبلغ روی سرور حساب می‌شود: قیمت فوری با یک «توکن قیمت» امضاشده (۱۵ دقیقه اعتبار، مخصوص همان همکار و همان نقطه‌ی نقشه) به سفارش
می‌چسبد، پس نه می‌شود مبلغ را از گوشی دستکاری کرد و نه از قیمت منقضی استفاده کرد.

**قیمت پیک فوری فعلا «تخمینی» است:** مبلغ پایه + کیلومتر × نرخ (با حداقل مبلغ)، که از «بیشتر ← اطلاعات آزمایشگاه ← پیک و ارسال» تنظیم
می‌شود و در اپ با برچسب «قیمت تقریبی» نشان داده می‌شود. برای گرفتن قیمت واقعی از اسنپ‌باکس (یا الوپیک) باید آزمایشگاه حساب
کسب‌وکاری و کلید API بگیرد؛ بعد یک `courierQuoter` برای آن در `backend/courier.go` اضافه و با `MELOPET_COURIER_PROVIDER` انتخاب می‌شود.
سفارش پیک هم هنوز دستی توسط ادمین ثبت می‌شود (نام و شماره‌ی پیک).

## نسخه نمایشی (بدون نصب و بدون سرور)

برای اینکه بررسی‌کننده مجبور به دانلود و نصب APK نباشد، یک **نسخه وب نمایشی** وجود دارد: کل اپ داخل مرورگر اجرا می‌شود و به جای سرور واقعی، یک سرور شبیه‌سازی‌شده با داده‌های نمونه (`app/lib/services/demo/`) دارد.

- روی صفحه ورود دو دکمه ورود سریع هست: **پنل کلینیک** و **پنل مدیر**. ورود با هر شماره `09...` و کد `1111` هم کار می‌کند (ثبت‌نام را می‌شود امتحان کرد).
- داده‌ها فقط در حافظه مرورگر می‌مانند و با رفرش صفحه به حالت اول برمی‌گردند.
- ساخت: `cd app && flutter build web --release --no-web-resources-cdn --pwa-strategy=none --dart-define=DEMO=true`
- **آدرس ثابت (GitHub Pages):** `https://amirhossein-shariat.github.io/Melopet/` — هر تغییری در `app/` خودکار منتشر می‌شود (workflow: `Deploy web demo`). یک بار در Settings ← Pages ← Source گزینه **GitHub Actions** را انتخاب کنید.
- داخل APK هم می‌شود حالت نمایشی را روشن کرد: روی صفحه ورود **روی لوگو انگشت را نگه دارید ← حالت نمایشی**.

## ورود با کد پیامکی

- `POST /api/melopet/auth/request-code` کد ۴ رقمی می‌فرستد؛ `POST /api/melopet/auth/verify` آن را بررسی می‌کند. شماره‌ای که قبلا ثبت‌نام کرده وارد می‌شود و شماره جدید به ثبت‌نام می‌رود. ساخت حساب جدید بدون کد تاییدشده در سرور رد می‌شود.
- هر کد ۵ دقیقه اعتبار دارد، حداکثر ۵ بار اشتباه، و ارسال مجدد حداقل ۲۰ ثانیه بعد.
- **حالت آزمایشی (فعلی):** پنل پیامک هنوز وصل نیست، پس تا وقتی `MELOPET_SMS_TEST_MODE=false` نشده، کد همیشه **۱۱۱۱** است (قابل تغییر با `MELOPET_SMS_TEST_CODE`) و پیامکی ارسال نمی‌شود. **در این حالت هر کسی که شماره یک کلینیک را بداند می‌تواند وارد حساب آن شود**؛ پس سرور آزمایشی را به اطلاعات واقعی وصل نکنید.
- برای استفاده واقعی: تابع `sendSMS` در `backend/otp.go` را به پنل پیامک خودتان (کاوه‌نگار، ملی‌پیامک و ...) وصل کنید و `MELOPET_SMS_TEST_MODE=false` بگذارید.
- حساب ادمین هیچ‌وقت با کد وارد نمی‌شود (فقط شناسه ادمین + رمز).

## دریافت APK

APK **خودکار ساخته نمی‌شود**؛ هر push فقط بررسی کد (analyze و تست) و ساخت سرور را انجام می‌دهد. برای ساخت APK:

**Actions ← Build Melopet ← Run workflow** (در صورت نیاز آدرس سرور را در فیلد `api_url` بنویسید) یا یک تگ مثل `v1.0.0` بزنید.

بعد از ساخت، فایل در **Releases ← latest-build** (یا Artifacts همان اجرا) قرار می‌گیرد.

آدرس سرور داخل APK قرار می‌گیرد. دو راه:
1. **Settings ← Secrets and variables ← Actions ← Variables** یک متغیر `API_URL` (مثلا `https://api.melopet.ir`) بسازید، یا
2. هنگام Run workflow آدرس را در فیلد `api_url` وارد کنید.

برای تست هم می‌توانید در صفحه ورود **روی لوگو انگشت را نگه دارید** و آدرس سرور را عوض کنید یا «حالت نمایشی» را روشن کنید.

> امضای نسخه نهایی: یک keystore بسازید و در Secrets مقادیر `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD` را بگذارید. بدون آن، APK با کلید debug امضا می‌شود (برای تست کافی است، برای کافه‌بازار/مایکت نه).

### نقشه
نقشه داخل اپ از OpenStreetMap استفاده می‌کند. اگر در شبکه کاربر بدون فیلترشکن بارگذاری نشود، صفحه انتخاب مکان پیام می‌دهد و با دکمه «موقعیت من» هم می‌شود مکان را ثبت کرد. برای ارائه‌دهنده دیگر هنگام ساخت بنویسید: `--dart-define=MAP_TILE_URL=https://.../{z}/{x}/{y}.png`.

## راه‌اندازی سرور

سرور یک فایل اجرایی است (بدون نیاز به دیتابیس جدا). روی یک VPS ایرانی (مثلا ابرآروان، پارس‌پک) اجرا کنید تا برای کاربران داخل ایران سریع و بدون فیلتر باشد.

```bash
# فایل melopet-server-linux-amd64 را از Artifacts یا Release دانلود کنید
chmod +x melopet-server-linux-amd64

# رمز ادمین اولیه (فقط در اولین اجرا اعمال می‌شود)
export MELOPET_ADMIN_MOBILE=09xxxxxxxxx
export MELOPET_ADMIN_PASSWORD='یک-رمز-قوی'
export MELOPET_ADMIN_ID=melopet            # شناسه ورود ادمین

./melopet-server-linux-amd64 serve --http=0.0.0.0:8090
# یا با دامنه و HTTPS خودکار:
./melopet-server-linux-amd64 serve api.melopet.ir
```

- اگر متغیرها را تنظیم نکنید، ادمین پیش‌فرض: شناسه `melopet` (یا موبایل `09000000000`) و رمز `melopet-admin-1234` — **فورا رمز را عوض کنید** (پروفایل ← تغییر رمز).
- ادمین در همان صفحه ورود اپ، به جای شماره موبایل، شناسه ادمین را وارد می‌کند. همکاران نمی‌توانند برای خود شناسه ادمین بسازند.
- لوکیشن آزمایشگاه برای «تماس با ما»: پنل ادمین ← بیشتر ← اطلاعات تماس آزمایشگاه ← لوکیشن.
- داشبورد مدیریتی دیتابیس: `https://آدرس-سرور/_/` (اولین بار یک superuser بسازید: `./melopet-server superuser upsert EMAIL PASS`). از اینجا می‌توانید ادمین جدید بسازید (کاربری با `role = admin`)، بکاپ بگیرید و ...
- `MELOPET_AUTO_APPROVE=true` ← همکاران جدید بدون تایید ادمین بتوانند پیک درخواست کنند.
- همه داده‌ها در پوشه `pb_data` کنار فایل است؛ از آن بکاپ منظم بگیرید (داشبورد ← Settings ← Backups).

### اجرای محلی برای توسعه
```bash
cd backend && go run . serve                      # سرور روی 127.0.0.1:8090
cd app && flutter run --dart-define=API_URL=http://10.0.2.2:8090   # امولاتور اندروید
```

## داده‌های اولیه (از عکس‌های نرم‌افزار آزمایشگاه)

| آزمایش | قیمت همکار |
|---|---|
| CBC | ۴۰۰٬۰۰۰ |
| AST، ALT، ALP، Chol، TG، Glu، GGT | ۹۵٬۰۰۰ |

- همه‌ی همکاران یک قیمت می‌بینند (سطح‌بندی حذف شد)؛ از **پنل ادمین ← آزمایش‌ها** قیمت‌ها را تغییر دهید.
- قیمت GGT همکار در عکس دیده نمی‌شد، ۹۵٬۰۰۰ فرض شد.
- واحد پول «تومان» فرض شده (در `app/lib/utils/format.dart` ← `kCurrency` قابل تغییر است).
- محدوده‌های مرجع سگ و گربه مقادیر رایج منابع هستند و **باید توسط مسئول فنی با دستگاه‌های خود آزمایشگاه بازبینی شوند** (از پنل ادمین قابل ویرایش‌اند).
- بقیه بخش‌ها (Urinalysis، Fluid، Culture، Hormone، Biopsy، PCR و ...) دسته‌بندی‌شان آماده است؛ با فرستادن لیست کامل اضافه می‌شوند. آزمایش‌های بدون پارامتر عددی (مثل کشت یا بیوپسی) یک کادر «گزارش متنی» دارند.

## لوگو
لوگوی فعلی موقت است (قطره خون + پنجه). برای جایگزینی:
1. فایل PNG مربع ۱۰۲۴×۱۰۲۴ را در `app/assets/images/logo.png` بگذارید و اجرا کنید: `python3 app/tool/make_icons.py --from app/assets/images/logo.png`
2. ویجت `MelopetLogo` در `app/lib/widgets/logo.dart` را با `Image.asset('assets/images/logo.png')` عوض کنید.

## نوتیفیکیشن
- وقتی اپ باز یا در پس‌زمینه است: لحظه‌ای (Realtime).
- وقتی اپ بسته است: هر ~۱۵ دقیقه یک بررسی پس‌زمینه (WorkManager) اعلان‌های جدید را نشان می‌دهد.
- این روش به سرویس‌های گوگل وابسته نیست و در ایران کار می‌کند. برای اعلان **کاملا آنی** با اپ بسته، می‌توان بعدا سرویس پوشه (Pushe) یا نجوا یا FCM را به تابع `notify()` در `backend/hooks.go` وصل کرد — ساختار داده تغییری نمی‌کند.
